# Customer Segmentation (K-means)

Лабораторна робота «Basic Part», Fundamentals of Data Mining 2026.
Сегментація клієнтів методом K-means на датасеті Mall Customers.

- `customer_segmentation.ipynb` – ноутбук з аналізом і результатами
- `data/Mall_Customers.csv` – датасет
- `requirements.txt` – залежності

```bash
pip install -r requirements.txt
jupyter notebook customer_segmentation.ipynb
```
